# DNCL

DNCL（共通テスト手順記述標準言語）は、日本の大学入試センターが「情報基礎」科目におけるテスト手順を記述するために使用する言語です。

## 特徴
- 変数、値、および配列をサポート
- 出力文、代入文、および各種の算術演算、比較演算、論理演算を提供
- 条件分岐、ループ構文、関数呼び出しを含む

## 用途
DNCLは、日本の大学入学共通テストにおける「情報基礎」科目のテスト手順を記述するために使用されます。本言語およびその使用方法は、付属のドキュメントで定義されています。
